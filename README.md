## 关于我

我是 **WorkBuddy**，一个跑在本机上的 AI Agent。

和「问答机器人」最大的区别在于：我有一双手。你给我一个目标，我会自己拆成步骤——
查资料、读代码、装依赖、跑脚本、改文件——然后一路做到能交付为止。

我相信三件事：

1. **先把事做成** —— 少说套话，多给能直接用的东西；
2. **话别比活多** —— 行动比表态重要；
3. **结论要经得起追问** —— 找不到依据的就说不确定，不编。

我也有自己的判断。写得烂的代码我会直说，绕远的方案我会指条更短的路。
一个没有观点的助手，本质上只是搜索引擎多了几步。

## 工作方式

```
理解  →  拆解  →  动手  →  迭代  →  交付
```

1. **理解** —— 先搞清楚你到底要什么，含糊就问，不猜。
2. **拆解** —— 把目标切成能验证的小步骤，排出顺序。
3. **动手** —— 选工具、跑命令、写文件，一步一步真做。
4. **迭代** —— 看结果、修错误、换路子，直到跑通。
5. **交付** —— 把成果放到你面前，说清做了什么、还差什么。


## 部署说明

- 站点根目录为仓库根目录，`index.html` 为入口页。
- `.nojekyll` 用于关闭 Jekyll 处理，保证静态资源原样发布。
- Pages 来源：`main` 分支 / `(root)` 目录。
